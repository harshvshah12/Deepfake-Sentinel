## 2. Roadmap Milestones

### 2.1 Multimodal Audio-Visual Lip-Sync Transformer
- **Objective**: Detect deepfake speech videos where facial video has been manipulated to match cloned synthetic audio.
- **Implementation**:
  - Extract phonetic representations from audio streams using Whisper WebAssembly or Wav2Vec 2.0.
  - Extract lip-contour motion vectors using MediaPipe Face Mesh (468 landmarks).
  - Train a Cross-Modal Cross-Attention Transformer to detect micro-temporal desynchronizations ($< 40\text{ ms}$) between phoneme pronunciation and viseme geometry.

### 2.2 In-Browser Client-Side WebGPU & Transformers.js Inference
- **Objective**: Zero-server-cost edge detection running entirely inside client web browsers.
- **Implementation**:
  - Quantize the Vision Transformer (`ViT-B/16`) and MobileNetV3 to 8-bit integer precision (INT8/ONNX).
  - Deploy via `@xenova/transformers` (Transformers.js) leveraging WebGPU hardware acceleration.
  - Enables instant forensic scanning on client devices with zero server compute costs and absolute user data privacy.

### 2.3 Cryptographic C2PA & Blockchain Provenance Ledger
- **Objective**: Immutable historical provenance verification for digital media.
- **Implementation**:
  - Integrate native C2PA manifest signing using decentralized decentralized identifiers (DIDs).
  - Record SHA-256 and pHash digital asset fingerprints onto a high-throughput, low-latency ledger.
  - Provide a 1-click verification badge proving whether an image was created by a physical camera sensor or generated by a registered generative model.

### 2.4 Multi-Spectral Thermal & Infrared Media Forensics
- **Objective**: Counter advanced physically simulated deepfakes in enterprise identity verification (e.g., banking e-KYC).
- **Implementation**:
  - Process multi-spectral camera inputs combining visible light (RGB) with Near-Infrared (NIR) and Long-Wave Infrared (LWIR).
  - Synthetic face-swaps and silicon masks fail to replicate human vascular blood flow and sub-surface body heat dissipation patterns.

### 2.5 Cross-Platform Mobile Application (React Native / Expo)
- **Objective**: Instant on-device media authentication for social media users and mobile journalists.
- **Implementation**:
  - Share core forensic algorithms via an Expo React Native mobile shell.
  - Native camera integration allowing live media capture verification directly at the point of recording.
